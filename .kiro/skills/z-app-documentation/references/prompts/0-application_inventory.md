# Application Inventory Documentation

Generate a comprehensive application inventory for {application_name}.

## DISCOVERY TASKS

Use the available tools to:

1. **Explore the Codebase**
   - Identify the root directory structure
   - Find configuration files (application.properties, application.yml, config.json, etc.)
   - Locate package.json, pom.xml, build.gradle, requirements.txt, or similar dependency files
   - Search for README files and documentation
   - Identify main entry points (main classes, app.py, index.js, etc.)

2. **Analyze Technology Stack**
   - Programming languages (scan file extensions: .java, .py, .js, .cs, etc.)
   - Frameworks (Spring, Django, Express, .NET, etc.)
   - Build tools (Maven, Gradle, npm, pip, etc.)
   - Testing frameworks
   - Frontend technologies (React, Angular, Vue, etc.)

3. **Database Analysis**
   - Query database metadata to list all databases/schemas
   - Identify database type and version
   - Count tables, views, stored procedures
   - Estimate database size (row counts for major tables)
   - Identify database users and roles

4. **Identify Dependencies**
   - Internal dependencies (modules calling each other)
   - External libraries and packages (with versions)
   - System dependencies (OS, runtime versions)
   - Third-party services/APIs referenced in code

5. **Infrastructure Indicators**
   - Docker files (Dockerfile, docker-compose.yml)
   - Kubernetes manifests
   - Cloud configuration (AWS, Azure, GCP config files)
   - Deployment scripts

## GENERATION GUIDELINES

1. **Be Comprehensive:** Examine as many files and configurations as possible
2. **Use Actual Data:** All counts, versions, and paths must be from actual exploration
3. **Infer Intelligently:** Make reasonable inferences based on naming and context
4. **Highlight Risks:** Call out security issues, outdated dependencies, technical debt
5. **Be Specific:** Provide file paths, line numbers, concrete examples
6. **Format Consistently:** Use markdown tables for structured data
7. **Add Context:** Explain significance of findings
8. **Prioritize:** Focus on most important discoveries first
